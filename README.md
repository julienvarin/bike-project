# Trek 970 → City Build

A single-page, Blue Lug–style field manual for converting a 1990s Trek 970
mountain bike into a considered city bike — what each part is, what to change,
and what to buy.

**Live site:** published via GitHub Pages (see the repository's Pages settings).

## Contents
- `index.html` — the whole site, self-contained (HTML + CSS + a little JS).
- `images/` — line-art SVG illustrations for each part. Swap any `<img>` in
  `index.html` for your own photo to personalise it.
- `.github/workflows/deploy-pages.yml` — deploys the site to GitHub Pages on
  every push.

## Local preview
Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
